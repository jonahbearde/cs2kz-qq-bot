# 04: Ubuntu 部署与上线运维手册

**What to build:** 机器人在维护者的 Ubuntu 服务器上成为常驻服务，且维护者仅凭手册即可完成测试群→正式 Target Group 的切换与全部日常运维。交付：部署章（apt 装 Python、venv、systemd 单元：开机自启+崩溃自动拉起、日志位置）、上线章（切换 Target Group 步骤）、日常运维章（加贴士、看日志、重启）、排错对照表。验收终点：正式群按时收到 Tip，项目完成。

**Blocked by:** 03（决策核心——部署与运维文档针对的是完整行为）

**Status:** ready-for-agent

- [ ] 部署章按"服务器未预装 Python"编写：apt 安装 Python ≥3.8、venv、依赖安装、.env 放置，命令可直接复制执行
- [ ] 提供 systemd 单元：开机自启、崩溃自动重启；安装/启用/启动/查看状态命令齐全
- [ ] 服务器实测：服务常驻、测试群收到 Tip、重启服务器后服务自动恢复发送（人工检查点）
- [ ] 上线章：切换正式 Target Group 全流程——正式群就位（维护者为群主）并开主动发言开关 → 群内 @ 机器人从日志捕获新 group_openid → 更新 .env → 重启；机器人在所有非目标群保持沉默
- [ ] 日常运维章：编辑 Tip List 热加载生效、查看日志、重启服务——无需任何代码知识
- [ ] 排错对照表至少覆盖：主动发言开关未开、openid 错误/过期、AppSecret 重置、机器人掉线、平台限频、Tip List 为空
- [ ] 最终验收：维护者照手册走完全程，正式 Target Group 按节奏收到 Tip（人工检查点）
