# 采用官方 QQ 机器人平台，而非 NapCat/OneBot

机器人只需在单个 QQ 群定时发送静态小贴士。我们选择 q.qq.com 官方机器人平台（个人主体）：官方已于 2026-06-22 全量恢复群聊主动推送，群主开启「机器人主动在群聊内发言」后即可定时推送（官方公告明确点名该场景），因此无需 QQ 小号、无封号风险、无需常驻第三方 QQ 客户端。代价是依赖平台注册与实名认证流程，且个人主体机器人只能加入创建者本人担任群主/管理员的群。

NapCat（OneBot 协议端）作为备选被放弃：需要小号跑 NTQQ 客户端、有账号风控风险、生态不稳定（go-cqhttp 已停止维护，NapCat 社区 2026 年初也经历过动荡）。

前提：维护者是目标群的群主或管理员（已确认为群主）。
