# 第一章 平台之路：注册、创建机器人、测试群就位

> 本章是《CS2KZ QQ 小贴士机器人操作手册》的第一章，面向零部署经验的维护者。
>
> **本章目标**：从"什么都没有"走到"测试群里躺着一个已开主动发言权限的官方机器人"，并且你手里妥善保存着 AppID/AppSecret。
>
> **完成标志**：QQ 开放平台个人主体认证通过；机器人已创建；AppID/AppSecret 已安全保存；自建测试群里能看到机器人；群主已开启「机器人主动在群聊内发言」。
>
> 注意：本章结束时机器人**程序还没有运行**，它在群里不会真的说话——这是正常的。让机器人发出第一条 Tip 是下一章的事。

---

## 0. 开始之前

### 0.1 全程路线图

```
注册开放平台账号 → 绑定管理员 + 个人实名（人脸识别）
→ 创建机器人 → 拿到并保存 AppID/AppSecret
→ 自建测试群 → 手机 QQ 拉机器人入群
→ 群主开启「机器人主动在群聊内发言」→ 本章验收
```

材料齐全的话，全程大约 30–60 分钟；实名认证环节如果卡住（信息不一致、人脸不通过），时间会更长。每一步都有 **✅ 检查点**，确认通过再往下走，不要跳步。

### 0.2 材料清单

| 材料 | 要求 | 说明 |
| --- | --- | --- |
| 一个邮箱 | 能正常收信 | 一个邮箱只能注册一个开放平台主体；**邮箱进入激活步骤后即被占用、不可修改**，请用你长期能访问的邮箱 |
| 管理员 QQ | 本人常用、已实名、账号状态正常 | **必须用正式 Target Group 的群主 QQ 来当管理员**（原因见 0.3）。后续所有扫码验证都用这个 QQ |
| 手机一部 | 已安装**最新版**手机 QQ（iOS 或 Android） | 用于扫码绑定、人脸识别、拉机器人入群、开权限开关 |
| 身份证 + 手机号 | 姓名、身份证号、手机号三者的运营商实名登记信息**必须一致** | 手机号须是用同一人身份证实名登记的号码，否则实名校验会报错 |
| 本人 | 人脸识别须本人完成 | 不能代办 |

> **✅ 检查点 0**：上表五项全部备齐；确认你准备当管理员的 QQ 就是正式群的群主 QQ；手机 QQ 已更新到应用商店里的最新版本。

### 0.3 先明白两件事（政策背景）

**为什么走官方平台？** 本项目选择 q.qq.com 官方 QQ 机器人平台（个人主体），不用 QQ 小号、不跑第三方客户端，无封号风险（决策记录见仓库 `docs/adr/0001-official-qq-bot-platform.md`）。平台曾在 2025 年 4 月暂停机器人主动消息推送，又于 **2026-06-22 全量恢复群场景主动推送**：群主打开「机器人主动在群聊内发言」后，机器人即可定时推送（官方公告明确点名"定时任务推送"场景）。本项目正是建立在这个前提上。

**个人主体的两条边界**（官方 FAQ 明确）：

1. 个人主体机器人**只能由创建者本人添加自己任群主/管理员的群**，不支持公开被其他人添加使用。本项目只在自己的群里用，完全不受影响——这也是 0.2 里强调"管理员 QQ 必须是正式群群主 QQ"的原因：将来正式群也要靠这个 QQ 拉机器人入群。
2. 新版机器人管理端下，管理员自己的群**可以直接使用：无需配置沙箱环境，也无需公开上架**。（旧版管理端的沙箱配置、上架审核流程已停止，网上旧教程里的"沙箱群""提审上架"步骤对本项目不适用，看到请跳过。）

平台政策有变动先例。若日后主动推送再次受限，以官方公告为准，并参考手册排错章。

### 0.4 关于界面与本章的核对方式

本章步骤已于 **2026-11-19** 对照官方文档核实（来源清单见文末第 11 节）：QQ 开放平台入驻文档（q.qq.com/wiki）、QQ Bot 介绍与接入指南（bot.q.qq.com/wiki）、QQ Bot 常见问题答疑（bot.q.qq.com/wiki/bot_FAQ/）等。bot.q.qq.com 与 bot.qq.com 是同一套官方文档的两个入口。

平台管理端和手机 QQ 的按钮名称、入口位置**可能随版本变化**，可能变化处均以「⚠️ UI 以实际为准」标注。遇到界面与本章描述不完全一致时，按相近的入口找同名功能即可；**以检查点是否通过为准**，不必逐字对照界面。

## 1. 注册 QQ 开放平台账号

官方提供两种注册方式，任选其一。**无论哪种方式，创建机器人前都必须完成个人主体认证（第 2 节）。**

### 方式 A：邮箱注册（推荐，流程完整）

1. 浏览器打开 QQ 开放平台 <https://q.qq.com/>，点击【立即注册】（⚠️ UI 以实际为准）。
2. 填写邮箱、设置密码。
3. 平台向邮箱发送激活邮件：去邮箱点击邮件中的链接完成激活。激活成功后页面会自动打开，继续填写超级管理员信息。
   - 收不到邮件：先翻**垃圾箱**，再回页面点"重新发送"。
   - 提示邮箱已注册：说明这个邮箱以前注册过，直接去登录界面登录即可，不要重复注册。

### 方式 B：QQ 账号快捷注册

在开放平台登录页选择用 QQ 账号注册/登录，按提示快捷绑定管理员。此方式注册后**仍需认证主体**才能创建机器人，接着做第 2 节即可。

> **✅ 检查点 1**：邮箱已激活（方式 A），或已能用 QQ 账号登录开放平台（方式 B）；页面进入"填写超级管理员信息"步骤，或已能进入开放平台控制台。

## 2. 绑定超级管理员 + 个人主体实名认证

1. **填写超级管理员信息**：姓名、身份证号、手机号，获取并填写短信验证码；然后用**管理员 QQ**（手机 QQ）扫码绑定（⚠️ UI 以实际为准）。
   - 官方明确要求：**姓名和身份证号码务必与手机号码对应运营商实名登记的信息一致**，否则会提示错误。三者不是同一人实名时，请先换用本人实名的手机号。
2. **选择主体类型：个人**。企业/个体户需要营业执照，个人不需要；按页面填写个人身份信息（姓名、身份证号）。
3. **人脸识别**：由**本人**使用刚绑定的手机 QQ 扫描二维码，进入人脸识别与验证流程，按提示完成。通过后即完成全部注册流程。
4. 认证通过后即可正常登录开放平台，进入应用管理页。

> **✅ 检查点 2**：用管理员 QQ 扫码登录 <https://q.qq.com/> 成功，能看到控制台/应用管理页面，主体状态显示个人认证已通过（⚠️ UI 以实际为准）。
>
> 卡住时：实名信息报错 → 核对"姓名 + 身份证 + 手机号运营商实名"三者一致；人脸不通过 → 确认是本人操作、光线充足，按页面提示重试。

---

## 3. 创建机器人

1. 登录开放平台后，进入**机器人管理端**入口（应用管理页中的"机器人"，⚠️ UI 以实际为准）。
2. 点击【创建机器人】。个人主体最多可创建 **5 个**机器人，本项目用 1 个。
3. 填写机器人资料：头像（可用默认）、昵称、简介。
   - 昵称建议直白体现用途，例如"CS2KZ 小贴士助手"。
   - 创建报错时检查资料规范：避免冒充官方、侵权、低俗等有害内容（官方提示）。
4. 如出现"设置 AI 服务"步骤：本项目是自研机器人，点【稍后连接】**跳过**（⚠️ UI 以实际为准）。
5. 创建成功后，机器人出现在管理端列表里；同时它一般会给你的管理员 QQ 主动发来一条消息（欢迎消息），QQ 消息列表里会出现与它的会话。

> **✅ 检查点 3**：管理端机器人列表里能看到刚创建的机器人；手机 QQ（管理员 QQ 登录）消息列表里出现该机器人的会话。
>
> 创建失败提示"创建失败" → 检查主体是否已认证、当前登录的是否为超级管理员；提示"当前 QQ 账号状态异常" → 管理员 QQ 账号存在合规异常，需先恢复账号正常状态。

## 4. 拿到并妥善保存 AppID / AppSecret

> ### ⚠️⚠️ 全章最重要的警示
> **AppSecret 只在生成/重置时明文显示一次，离开页面后就再也看不到了。**
> 看到它的第一时间就复制保存好。忘记保存没有"再看一眼"的办法，**只能重置**——重置后旧密钥立即作废，所有用到旧密钥的地方都要换新。

1. 在管理端点击刚创建的机器人，进入机器人管理页。
2. 找到【开发】→【开发设置】（⚠️ UI 以实际为准），页面上有 **AppID** 与 **AppSecret** 两项：
   - **AppID**：机器人 ID，一串数字，随时可以复制。
   - **AppSecret**：机器人密钥。若尚未生成，点【生成】；此时会要求**管理员 QQ 扫码验证身份**，验证后弹出重置/生成窗口，确认后明文显示 AppSecret。
3. **立即**把两个值复制到安全的地方（见下方保管要求）。

**保管要求（务必遵守）：**

- 推荐存进密码管理器，或本地加密笔记；临时写在本地记事本里也可以，但部署完成后应清理。
- **不要**通过 QQ/微信聊天、邮件发送这两个值；**不要**提交进 Git 仓库；**不要**写进任何文档正文（包括本手册）。
- 后续部署章会把它们放进服务器的 `.env` 文件（该文件不入仓库）。在那之前，它们是"只存在你一个人手里"的秘密。
- AppSecret 与 AppID 配对使用：AppID 类似账号，AppSecret 类似密码。泄露 AppSecret 等于别人能冒充你的机器人发消息；一旦怀疑泄露，立即重置。

**重置路径**（忘记保存或怀疑泄露时）：同一【开发设置】页面 → AppSecret →【重置】→ 管理员 QQ 扫码验证 → 保存新值。若提示无法重置：检查主体是否已认证、当前账号是否为超级管理员、账号资质是否异常（管理端右上角头像 → 账户信息查看）。

> **✅ 检查点 4**：AppID 与 AppSecret 两个值都已保存在只有你能访问的地方；聊天记录、代码仓库、任何文档里都没有它们。

## 5. 自建测试群

调试阶段不拿正式群刷屏：先建一个专门的测试群。**调试期间测试群临时充当 Target Group**（机器人只向配置的目标群发 Tip）；验收完成后按上线章切换到正式群，之后机器人在测试群保持沉默。

1. 手机 QQ 登录**管理员 QQ**（也就是机器人创建者、正式群群主）。
2. 新建一个群聊（消息页右上角【+】→【创建群聊】，按提示完成，⚠️ UI 以实际为准）。**创建者自动成为群主。**
3. 群名建议与正式群明显区分，例如"CS2KZ 机器人测试群"。可以只留自己，或拉一两位朋友帮忙观察。

> **✅ 检查点 5**：测试群已建成；群资料/群设置里显示你是**群主**；群名不会与正式群混淆。

---

## 6. 拉机器人进测试群（最新版手机 QQ）

前提回顾：个人主体机器人只能进**创建者本人任群主/管理员**的群；操作必须在**最新版手机 QQ** 上、用**管理员 QQ** 登录进行。

**主路径**（⚠️ UI 以实际为准）：

1. 手机 QQ →【联系人】→【机器人】页签 → 找到你创建的机器人，点进它的**资料页**。
   - 也可以从消息列表里打开机器人会话（第 3 节它给你发过消息）→ 右上角进入资料页。
2. 资料页下方找到【添加到群聊】，选择你的**测试群**。列表里只会出现你任群主/管理员的群。
3. 若入群时弹出【设置权限】入口，直接点进去，接着做第 7 节。

**备选路径**：主路径找不到入口，或提示"机器人暂不支持加入"时——

- 确认手机 QQ 已升到最新版本（iOS/Android 都要最新版）；
- 确认你在该群是群主或管理员；
- 按官方 FAQ 建议**尝试手机端扫码添加**：在机器人管理端找到机器人二维码入口（如"扫码聊天"，⚠️ UI 以实际为准），用手机 QQ 扫码打开机器人资料页，再添加到群聊。

> **✅ 检查点 6**：测试群的**群成员列表**里能看到机器人。
>
> 仍提示"暂不支持加入"：多半是 QQ 版本过旧或你在该群不是群主/管理员；逐一排除后换扫码路径重试。

## 7. 群主开启「机器人主动在群聊内发言」

这是本项目能定时发 Tip 的**关键开关**：2026-06-22 恢复的群主动推送能力，默认在每个群是关闭的，必须由**群主**手动打开。

1. 用**群主身份**（你自己的管理员 QQ）、在**最新版手机 QQ** 上操作。
2. 打开机器人的群消息设置，两个入口任选（⚠️ UI 以实际为准）：
   - 入群时弹出的【设置权限】；
   - 或：测试群 → 群聊设置 → **群成员列表 → 点击机器人头像** → 机器人资料页 → 右上角设置。
   - 官方 FAQ 特别提醒：这里设置的是**机器人在本群的消息权限**，不是"机器人权限设置"，别找错地方。
3. 打开 **【机器人主动在群聊内发言】** 开关。
4. 另一项「机器人可获取的群聊消息范围」：本项目只需要接收 **@ 机器人的消息**（用于捕获群标识，见下一章），保持默认即可，**无需**设为"获取群内全部消息"。若下一章 @ 机器人后日志里没有捕获到群标识，再回来把该项设为"获取群内全部消息"重试。

> **✅ 检查点 7**：「机器人主动在群聊内发言」开关处于**开启**状态。
>
> 此时机器人程序还没运行，群里不会有任何消息，无法用"发一条试试"来验证——真实发送验证在下一章完成。若日后发送时报错 `40034105`（主动消息发送失败，无权限），第一个要回来检查的就是这个开关。

## 8. 顺手确认：连接方式为 WebSocket

1. 回到网页管理端 → 机器人管理页 →【开发设置】→【事件订阅与回调地址】（⚠️ UI 以实际为准）。
2. 确认连接方式选的是 **WebSocket**（默认即是）。官方说明：WebSocket 不依赖公网服务器部署，适合个人使用——本项目**无需公网 IP、域名或 Webhook**。若当前是 Webhook，切换为 WebSocket（切换立刻生效）。
3. 同页的 **IP 白名单**本章可以先不设置（未设置时允许所有 IP 调用）；部署章拿到服务器出口 IP 后再添加，更安全。
4. 若管理端提示填写**隐私协议**或确认**服务范围**，按提示完成即可：个人主体默认只能被创建者添加进自己任群主/管理员的群，**无需公开上架**。

> **✅ 检查点 8**：连接方式显示为 WebSocket。

## 10. 常见问题速查（注册与平台环节）

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 收不到激活邮件 | 邮件进垃圾箱 / 发送延迟 | 翻垃圾箱；页面点重新发送 |
| 提示邮箱已注册 | 该邮箱注册过开放平台 | 直接登录，不要重复注册；邮箱激活后不可更换 |
| 实名校验报错 | 姓名/身份证与手机号运营商实名不一致 | 换用本人实名登记的手机号，确保三者一致 |
| 创建机器人提示"创建失败" | 主体未认证 / 非超级管理员 | 完成个人主体认证；用超级管理员账号登录 |
| 提示"当前 QQ 账号状态异常" | 管理员 QQ 账号合规状态异常 | 先恢复 QQ 账号正常状态再创建 |
| 管理端看不到机器人 | 登录的不是创建它的超级管理员 | 用创建机器人的超级管理员 QQ 登录 |
| AppSecret 无法重置 | 主体未认证 / 非超管 / 账号资质异常 | 逐项检查；管理端右上角头像 → 账户信息查看资质状态 |
| 忘了保存 AppSecret | 离开页面后不可再查看 | 开发设置 → 重置（扫码验证），保存新值；旧值作废 |
| 加群提示"机器人暂不支持加入" | QQ 版本过旧 / 非该群群主或管理员 | 升级最新版手机 QQ；确认群身份；尝试扫码添加 |
| 私聊机器人收到"去火星了，稍后再试"类提示 | 机器人程序尚未运行 | 正常现象，按下一章运行程序 |
| 机器人进群后不说话 | 程序未运行 / 主动发言开关未开 | 本章只就位平台；运行见下一章；开关见第 7 节 |
